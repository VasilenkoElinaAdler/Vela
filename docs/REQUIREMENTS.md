# Requirements
See MASTER_PLAN.md for approved scope and gates. Native Android, single Bubble Gum identity, offline six-category card game. No advertising, login, telemetry or network permissions. Initial 30 Spanish reference cards with stable IDs; all require coach approval. Four-language architecture, with only Spanish implemented at baseline. UI text resources independent from card data. No production release until review, testing and signing are complete.

## Mandatory size and efficiency requirement — 2026-11-27
Monitor package size at each build and update. Separate raw APK, artifact ZIP, AAB, device-specific compressed download and installed storage; compare like with like. Keep offline operation, avoid unnecessary libraries and duplicate images, prefer reusable vector diagrams and optimized raster assets. Measure the baseline and an optimized release-like build; enable R8/resource shrinking only with regression verification. Review size growth and budget overruns before release. Proposed targets of 5 MB (base) and 10 MB (expanded deck) are provisional pending measured feasibility and owner agreement on numeric limits. No mandatory extra content downloads.
